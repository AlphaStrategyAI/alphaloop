# alphaloop

0.2.0 在你自己的电脑上，只跑一项日频股票的均值回归，并把门禁结果写进一份可以拿走的记录。默认的自动迭代不超过 5 轮；这个上限可以改，用尽之后经你确认还可以再加。不下单，也不判断该不该用这个策略。

多只股票时，信号是近期收益的截面 z 分数。只有一只时，用它自己的滚动标准差。成交用上一根 bar 的信号。自动迭代只把回看天数加 5，不加别的参数。默认股票池是名单日的成分，不是当时的成分，回看更早的历史带有幸存者偏差。时点检查不看这件事：检查通过，不表示偏差已经被排除。

这是给已经会做日频回测、并且希望这几轮和没过的检查留在文件里的人。它不扫大量参数，也不替代能下单或能做别的策略的工具。

没有安装包，没有托管，也没有付费方案。命令行只能证明引擎进程在。一项研究要在桌面应用里做，而桌面要先打包引擎。

## 一个具体的任务

想看的是：近期跌得多的股票，会不会向近期均值靠拢。

常见做法是在笔记本里用收盘价算一个分数，换几组回看天数，把最好看的净值留下来。容易出问题的是三件事。信号和成交用了同一根 K 线的收盘价。试过的次数不在任何文件里。结果留在别人的网站上，带走的是图，不是当时的验证定义。

在 alphaloop 里，对话用来锁定五项设定：赚钱原理、标的、有效研究时间、第一轮验证方法、最低数据覆盖。有效研究时间不计暂停、也不计等待确认的时间。原理若写成动量、趋势或突破，确认卡和完成页会说明暂不支持；引擎仍只跑均值回归，不会改跑别的族。确认开跑之后，信号先算出来，成交用的是上一根 bar 的信号。第一轮回看天数从 20 起，入场 z 默认 1.0，方向默认只做多。默认自动迭代不超过 5 轮。那一次自动改动是把回看天数加 5，这个 5 写死在代码里，不是环境变量。换经济逻辑会停下来等你确认。

做完之后，导出策略包要五项同时成立：研究已完成；当前冻结的验证方法全部通过；没有待确认；当前轮里除时点一致性以外的重新验证全部通过（没有这类记录时，这一项算通过）；时点一致性已执行且通过。时点看的是当轮原来的结果，不看后来对时点的重验。它只检查被引用资料的发布日是否不晚于回测截止日。没有发布日的资料被排除，不因此判失败；一项研究可以在没有引用外部资料时通过这项检查。它不检查标的池是不是当时的成分，不检查复权，也不检查财务修订。幸存者偏差不会让这项失败，所以「时点通过」不能读成池子没有幸存者偏差。缺任何一项，只能导出研究记录。记录里的 `why_not_live.json` 列出没过的检查名，`manifest.json` 里 `live_handoff_eligible` 为 false。包里的回测是历史假设，不是实盘业绩，也不是对未来的承诺。

没有测量过这能省下多少时间。能看见的变化是：试验次数和没过的门禁留在记录里。

## 现在能做，以及做不到的

**能做**

- 在桌面应用里把五项设定谈完，确认后做历史研究。默认评审器是确定性的，不调用大模型。只有把 `ALPHALOOP_REVIEWER` 设为 `subagent`，并同时提供 `ALPHALOOP_LLM_BASE_URL`、`ALPHALOOP_LLM_API_KEY`、`ALPHALOOP_LLM_MODEL`，才会请求外部模型。缺任何一项就失败关闭，不会把超时当成通过。
- 不输入股票代码时，新研究使用仓库里的生成日名单。美股是 `us_equity_large_cap_v2`：2026-10-16 的标普 500 成分，503 只。A 股是 `cn_equity_large_cap_v2`：2026-10-19 的沪深 300 成份，300 只。已经引用 v1 的研究仍用各自 40 只的旧名单，成员不改。输入股票代码会换掉默认池。
- 这些名单是生成日的成分，不是历史时点成分。池文件里写着：「生成日名单，不是时点成分。用它回看更早的历史含有幸存者偏差。」界面注记是「非时点成分」，例如「取自标普 500 在名单日的成分，非时点成分」。规格要求研究记录里存 `survivorship_bias_untested`。0.2.0 的导出代码没有这个键。
- 导出研究记录。五项资格都通过时，才导出策略包。下游要自己实现执行。alphaloop 不连接券商。

**做不到，或还不能当成已经交付**

- 不下单，不接券商，不跑模拟盘。命令行只有启动和查看状态。
- 低波、股债再平衡、基本面因子、全天候在代码里有标识和中文名。开跑时返回「这一族还不能开跑。」
- 规格里的本地 CSV 导入、商业数据商连接器，以及设置里的数据源页、大模型页，界面上仍是稍后才会做的页面。现在能用的设置是界面语言：跟随系统、中文或英文。
- 规格要求把 Yahoo 和 AkShare 标成「未经许可」，并要你主动确认之后才能开跑。0.2.0 的代码按标的自动选用 `yahoo_daily` 或 `akshare_sina_daily`，界面写的是「雅虎日线」和「AkShare 日线（新浪优先）」。确认流程里没有那一次勾选。「未经许可」这个词在界面语言的术语 JSON 里，不在 [`docs/GLOSSARY.md`](./docs/GLOSSARY.md)。开跑会向这些来源发请求。机构网络上应先自己判断条款，不要把界面上的来源名当成已经获准的数据许可。
- 规格把导出资格写成还包含 `coverage_satisfied`。`strategy_pack_eligibility` 里没有这个键。覆盖不够会在运行过程中停下，但那不是导出函数里的一项检查。
- 没有发布日的资料不当作时点证据。检查范围见上面的导出条件，这里不重复。
- 没有可引用的用户数量、客户或业绩。2026-10-23 查看时，这个公开仓库没有 Release，讨论区关闭，开放 Issue 为空。

## 最快路径

需要 Python 3.12 和 Git。桌面还需要 Node.js 22、Rust，以及系统 WebView。类型检查工作流使用 Node 22。macOS 打包工作流写的是 Node 20，这里没有在 Node 20 上重跑桌面测试。Linux 上，CI 安装 `libwebkit2gtk-4.1-dev` 及其同组依赖。打引擎侧车还需要 `python3.12-venv`：2026-10-23 在没有这个包的机器上，`scripts/build_sidecar.sh` 退出码为 1，原因是虚拟环境里没有 ensurepip。2026-10-23 请求 `https://pypi.org/pypi/alphaloop/json` 返回 404，PyPI 上没有这个包。

```bash
git clone https://github.com/AlphaStrategyAI/alphaloop.git
cd alphaloop
python3 -m pip install -e ".[dev]"
python3 -m apps.cli.main start
python3 -m apps.cli.main status
```

`start` 之后，`status` 打印一行 JSON。这不是一项研究的结果。2026-10-23 在 Linux 上的一次输出如下，pid 每次不同：

```json
{"awaiting_confirm": false, "has_running_research": false, "owner": "cli", "pid": 11699, "running": true}
```

这只说明引擎进程在。命令行不能新建研究、不能确认、不能导出。没有 `stop` 子命令，结束时结束 `status` 里的 pid。

研究在桌面应用里做。桌面要先打包引擎侧车。这一步会自建 `.venv-sidecar`，并用 PyInstaller 打包，时间取决于机器和网络：

```bash
bash scripts/build_sidecar.sh
python3 scripts/stage_sidecar.py --target linux --source dist/alphaloop-engine --tauri-root apps/desktop/src-tauri
bash scripts/smoke_sidecar.sh
cd apps/desktop
npm ci
npm run tauri dev
```

macOS 把 `--target linux` 换成 `macos`，Windows 换成 `windows`。2026-10-23，在装上 `python3.12-venv` 之后，上述构建完成，`smoke_sidecar.sh` 打印了 `engine handshake ok: ready`。这一步没有打开窗口，也没有新建研究。

若命令行已经 `start` 过，先结束那个 pid，再开桌面。两边默认共用同一把运行时锁。

打开之后，在「研究」里新建一项。对话依次问那五项。提问里的例句是：原理「美股大市值股票的均值回归」；标的「美股股票」；有效研究时间「12 小时」；第一轮方法「分段稳健性检验、样本外稳定、集中度、换手成本」；覆盖「至少 25 个、10 年、缺失不超过 5%」。这不是推荐的投资参数，本次也没有在图形界面里把这五句跑完。A 股把原理和标的换成 A 股股票的均值回归。开跑会按标的拉取日线。不输入代码时，默认池是 503 或 300 只，计划窗口是从当天的 UTC 日期倒推 12×365 天。拉不到数据或覆盖跌破你认下的底线时，研究停下来说明原因，不会改用一份仓库里不存在的行情文件。五项锁定后出现确认开跑卡。完成后看完成页。有门禁没过时，能导出的是研究记录，策略包不可用，页面写明缺哪一项检查。五项都过，才导出策略包。

不访问行情的检查：

```bash
python3 -m pytest -q -m "not network"
cd apps/desktop && npm test
```

`pytest` 里有一条 Rust 契约测试。CI 会先放一个空的引擎占位再跑。本机既没有这个占位、也没有 GTK 开发包时，这一条会失败，其余离线测试不依赖它。

Linux 上，数据默认在 `~/.local/share/ai.alphastrategy.alphaloop`，里面有 `research.db`、`materials/`、`exports/`、`snapshots/` 和 `engine.log`。运行时的锁和 `owner.json` 在 `platformdirs` 的 `user_runtime_path("alphaloop")`。没有 `XDG_RUNTIME_DIR` 时，先用 `/run/user/<uid>`（这一处可用时）；否则才落到临时目录下的 `runtime-<uid>/alphaloop`。可以用 `ALPHALOOP_DATA_ROOT` 和 `ALPHALOOP_RUNTIME_ROOT` 改这两个位置。

## 凭什么相信，以及不要相信什么

可以核对的是仓库、许可证和一次本机运行。没有第三方审计，没有业绩案例。

MIT 许可证的版权行是 `Copyright (c) 2026 OpenStrategy Team`。GitHub 组织名是 AlphaStrategyAI。这份说明不证明这两个名字是同一个法律主体。文件里的 MIT 允许使用、修改、再分发这份代码，包括商用，前提是保留版权和许可声明。它不保证软件正确，也不授予任何行情、财报或指数成分数据的权利。没有贡献者协议。

美股日线经过 [yfinance](https://github.com/ranaroussi/yfinance)。该项目的 README 写明它不隶属 Yahoo，供研究与教育使用，并要求读者自己看 Yahoo 的使用条款。A 股日线经过 [AkShare](https://github.com/akfamily/akshare)，优先新浪，失败再试东财。AkShare 的 README 写明数据仅供学术研究，不构成投资建议，部分接口可能被移除。两个来源都可能失败或变更。产品规格要把它们标成未经许可；上面已经写了，0.2.0 的界面还没做到。

公开论文走 Crossref。发行人材料走 SEC EDGAR，请求使用固定的 User-Agent：`alphaloop/0.2 research@example.invalid`。这不是你的联系邮箱，也不要拿它代表一家机构。本次没有发送真实的 EDGAR 请求，不能声称这个身份会被接受。本机 Markdown 放在数据目录的 `materials/`。

个股日线按复权价请求：美股 yfinance 使用 `auto_adjust=True`，A 股 AkShare 使用前复权 `qfq`。股票基准仍是价格指数：美股代码 `SPX`，取数时换成 `^GSPC`；A 股 `000300.SH`，取数用指数日线。复权价的涨跌和价格指数不是同一口径。

新研究在确认开跑时把成本模型设为 `schedule_v1`。回测净收益按换手扣除：美股个股单边 5bp，美股基金 1bp，A 股个股 20bp，A 股基金 5bp。可持有的标的不少于 20 只、且不是基金、也不是多空时，单票权重上限是 5%。换手成本这道门禁是另一层：美股用 10bp，A 股用 20bp，从年化超额里减去「年化换手 × bp / 10000」。净收益已经扣过 `schedule_v1` 时，这道门禁仍会再减一次。下面只是算术，不是一次回测：若年化换手等于 1，美股门禁再减去 0.001。不要把回测里的 5bp 和门禁里的 10bp 加成 15bp。术语表里「回测收益序列本身不含逐日费用」说的是旧的 `legacy_zero` 路径；旧的 A 股记录在用冻结快照重新验证时仍走那条路径。A 股的完成页会写：「未模拟 T+1 与涨跌停，实际成交可能更差。」确认开跑卡上的是成本那一行，不是这句。A 股结果不能拿来判断真实成交。

同一数据窗口上的累计轮次写入 SQLite，并写入导出的 `history/rounds.json`。窗口键包含确认日，隔天重开是一个新窗口，累计不跟着走。累计变大不会放宽门槛。默认预算用尽后，每次继续迭代都要你确认。累计达到或超过 20 之后，每一次继续都要再确认一次，不是只在跨过 20 的那一次。轮次预算默认 5，用尽后追加的预算默认也是 5。回看天数加 5 是另一处写死的数，不由追加预算的变量控制。三个默认值在 `engine/research/honest_stop.py`，分别可用 `ALPHALOOP_MAX_TRIALS`、`ALPHALOOP_TRIAL_BUDGET_INCREMENT`、`ALPHALOOP_HIGH_SUSPICION_ROUNDS` 修改。

异常结果在界面上是一张已触发项的清单。文案是「夏普比率相对基线异常偏高」「数据覆盖相比开始时已缩减」「尝试次数相对基线异常多」。它不展开数据出处。「近期改过验证定义」这一项，当前完成页的计算把它的天数写成 30，而触发阈值是小于 7，所以这项不会出现。

## 和现有做法比

| 做法 | 它实际提供的 | 它不替你做的 |
| --- | --- | --- |

| [backtrader](https://github.com/mementum/backtrader) 1.9.78.123 | 事件驱动框架，GPLv3+。PyPI 上这一版发布于 2023-04-19。库内带券商接入。 | 上游发布停在该版本。它是交易框架，不是试验账本。 |
| [聚宽](https://www.joinquant.com/) | 在浏览器里研究、回测、模拟。官方 API 文档写明：财务数据按报告期查询会有未来函数；`use_real_price` 默认是 False。 | 研究在对方服务器上。会员收费页在 2026-10-23 抓取时返回 403，这里不写价格。 |
| [米筐量化平台](https://www.ricequant.com/doc/quant/) | 浏览器里的研究，数据来自 RQData。文档中的基础版没有模拟交易名额，企业版有。官方 PDF 写试用账户一个月。 | 正式数据价格要联系销售。这里不采用论坛里的报价。 |
| [LEAN](https://github.com/QuantConnect/Lean) | 引擎 Apache 2.0，可以在本机跑。QuantConnect 云是另一套带实盘的订阅。 | 本次没有从标价页核对到可以引用的金额。它的目标包含下单。 |

这些做法仍然更合适的情况很具体：你要做分钟或 tick，要接券商，要低波、股债、基本面或全天候，或者要别人维护好的财务数据。0.2.0 都不提供。若目标是在本机扫很多组参数，vectorbt 的 README 把扫描当成主路径。alphaloop 不提供这种扫描，也不替你留下「夏普最高的一组」。

## 许可、费用与参与

没有收费层，没有付费支持，也没有托管实例。2026-10-23 没有可以领走的开发任务，也不要把规格和代码的差距当成征稿。讨论区关闭，没有第二渠道。没有 `CONTRIBUTING`，没有贡献者协议。

行为若和本文件不一致，可以开 [Issue](https://github.com/AlphaStrategyAI/alphaloop/issues)。请写上日期、命令，以及 `status` 打出的 JSON；如果是导出，写上缺的是哪一项检查。不要为了实现低波、股债再平衡、基本面因子、全天候，或为了补上未经许可勾选、`coverage_satisfied`、英文族名，去改已经能跑的均值回归。[V1 交付收口](./docs/requirements/v1-cut-line.md) 里既有「已交付路径不要被后来的规格改写」，也有尚未落在代码上的句子（例如导出资格含 `coverage_satisfied`、界面标未经许可）。两句不要合成一个开发任务。以代码和本文件为准。

英文对照是 [README.en.md](./README.en.md)。两份文件这次一起改，没有自动对照检查。英文界面里，策略族的显示名目前是标识本身，例如 `mean_reversion`。

桌面有一个密钥保险库：优先系统钥匙串；没有系统钥匙串时，可以选本次会话或口令加密的本地文件。设置页还不能把这些密钥配成一项可用来源。不要把密钥写进 Issue。

## 已知限制

- 自动迭代的默认预算是 5 轮。设计稿若画了更多轮，以代码为准。回看天数加 5 与「再给 5 轮预算」不是同一个开关。
- 数据窗口键包含确认日。同一个想法隔天再开，是一个新窗口，累计轮次不继承。
- 自动迭代不搜索入场阈值，也不换策略族。只有一只股票时，z 分数不是截面比较。
- 「分段稳健性检验」是把一条已经算好的收益按时间切开比较，不是重新估计参数的 walk-forward。「集中度」看的是持仓权重，不是市场成交拥挤。对话里仍可输入旧称「走样检验」「拥挤度」。
- 回测里的 5bp 和门禁里的 10bp 不是同一个成本。见上面的成本两层。
- `pyproject.toml` 没有钉死依赖版本。2026-10-23 这次安装得到 pandas 3.1.0、yfinance 1.7.0、akshare 1.19.3。另一天安装，解析结果可能不同。
- 同日 `npm audit` 报告开发依赖中有 2 个中等、2 个高危问题；加上 `--omit=dev` 之后是 0。这不是安全审计结论。
