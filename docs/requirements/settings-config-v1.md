## 0. 这份文档是什么 / 与上游的关系

这是 alphaloop 的**设置功能**规格。设置里有两部分：数据源，和大模型。两部分共用第 1 节的密钥安全和测试连接。

上游是[产品定位](./product-positioning.md)和[产品设计 v0.0.1](./product-design-v0_0_1.md)。哪一族需要哪类数据，对照[策略族 v1](./strategy-families-v1.md)。定位优先。本文不改六种研究状态、四条交接资格和「不下单」。

本文不是实现方案。不写密钥的加密算法、不写数据库表、不写某个供应商 SDK 的函数名，也不写各家大模型的请求字段。

## 1. 共用规则：密钥安全与测试连接

数据源的密钥、大模型的 api key，以及任何能代替它们的刷新材料，都适用本节。

**存放。** 只放在本机的系统钥匙串或本机加密存储里。用户换电脑时，产品不把它们同步到云上。本机优先，没有云端钥匙串。

**不得出现在：**

- 研究对话、确认卡、结论页
- 迭代与验证记录
- 策略包和研究记录包
- 日志、错误信息和测试连接的失败说明
- 导出的文件名

研究记录可以写数据源的账户别名、大模型的模型名，以及接入地址的主机名（含端口，不含路径里的密钥、不含查询参数）。确认卡和策略包只出现别名、源的名称和拉取时间。

**测试连接。** 设置页上的测试不把密钥发到研究记录里。成功和失败都用白话。

- 成功：说明这一项现在可用，并给出第 2 节或第 3 节要求的那几项结果。
- 失败：说明人能看懂的原因，例如地址没有响应、密钥被拒绝、模型名不存在、历史长度不够。原因里不出现完整密钥，也不出现地址上的查询参数。

失败不自动改试另一个已配置的账户或模型。

## 2. 数据源

### 2.1 原则

研究数据是用户自己的。alphaloop 不内置一套替用户付费、替用户接受许可的默认行情库，也不把未经许可的自动采集当成可用数据。

用户配置的是**自己的账户**：有账户的数据商、免费但要表明身份的官方来源、或者自己的文件。确认使用之前，用户要明确写下：我有权把这份数据用于这次研究。产品把这句话记进研究，不代替用户去向数据商保证。

数据血缘一旦进了某一版研究，就不再悄悄换成另一家。换源、换代理证券，都开新版。

### 2.2 数据类别

产品只认下面五类。一个源可以覆盖其中几类，确认卡按类写，不按「这家什么都有」写。

| 类别 | 研究要用它做什么 | 不算数的情况 |
| --- | --- | --- |
| 行情与总回报 | 价格路径、波动、反转、再平衡后的收益 | 只有不复权价或价格指数，分红和票息被当成零 |
| 财报及发布日 | 基本面信号，以及发布时点 | 只有报告期、没有公开时点；修订回填到发布前 |
| 指数成分 | 按某个指数定义标的池，并知道何时加入、何时退出 | 只有今天的成分名单，却拿去回看更早的历史还不警示 |
| 行业分类 | 行业中性，或按行业过滤 | 没有时点，用今天的行业贴到历史持仓上还不警示 |
| 价差与成本 | 核对或替换产品已定的成本假设 | 把未知价差写成已经测过的全市场统计 |

成本数字本身有一部分不依赖数据商。[策略族 v1](./strategy-families-v1.md)已定：美市主流 ETF 单边 1 bp，美股个股单边 5 bp。个股 5 bp 是保守产品假设。没有价差数据源也可以开跑，结论页仍要标注这个假设。价差源是可选的。

### 2.3 每个策略族需要哪几类

「必须」是没有它就不能开跑这一族。「可选」缺了不挡住开跑，用了就要进血缘。

| 族 | 行情与总回报 | 财报及发布日 | 指数成分 | 行业分类 | 价差与成本 |
| --- | --- | --- | --- | --- | --- |
| 低波 | 必须。个股总回报 | 不需要 | 池子若定义为指数，必须有时点成分；用户给出固定名单时改为可选，并用名单就要警示幸存者偏差 | 可选 | 成本假设必须使用已定的个股 5 bp。价差源可选 |
| 股债再平衡 | 必须。已定代理 SPY 与 AGG 的总回报；若这一版改用 IEF，则是 SPY 与 IEF | 不需要 | 不需要 | 不需要 | ETF 单边 1 bp 必须使用。价差源可选 |
| 均值回归 | 必须。个股总回报 | 不需要 | 与低波相同 | 可选 | 与低波相同，另加 0/5/10/20 bp 敏感性 |
| 基本面因子 | 必须。个股总回报 | 必须。发布时点不晚于信号日 | 与低波相同 | 行业中性关闭时不需要；用户确认打开后必须有时点行业 | 与低波相同 |
| 全天候 | 必须。SPY、TLT、IEF、GLD、DBC 五只的总回报，共同起点不早于 2006-02-03 | 不需要 | 不需要 | 不需要 | ETF 单边 1 bp 必须使用。价差源可选 |

缺了「必须」的那一类，新建研究不能确认开跑，设置里引导用户去补这个源。不得用另一类数据顶上，也不得改跑另一个族。

### 2.4 三种源

**有账户的 API 数据商.** 用户填入自己的密钥或令牌，并选择这个账户覆盖哪些类别。产品用这个账户去取数，许可责任在用户和数据商之间。第 2.5 节列出本次核对过的五家，供设置页说明「可以对接」，不是五家里必须预装全部连接器才能发版。第一批至少要能配置其中的账户形态：密钥、测试连接、类别、历史长度。某一家的连接器若还没做，设置页写「尚未对接」，不要显示成已经连上。

**免费的官方来源.** SEC EDGAR 是这一类的已核对例子。它不发商业 API 密钥。用户要配置的是 **User-Agent 里的联系邮箱**，并确认自己会遵守公平访问：当前上限每秒 10 次请求。产品按这个身份去取提交记录和 XBRL，不把邮箱写成密钥，但也不把别人的邮箱拿来用。

EDGAR 能覆盖的是美国财报及发布日，以及公司当前的 SIC。它不提供总回报价格，也不提供时点化的指数成分。发布时点的用法沿用策略族规格：优先用 acceptanceDateTime；只有日期时，信号不早于下一交易日。companyfacts 会不会覆盖旧值，仍待定。待定未解开时，做不到保留旧值就判 PIT 不通过。

其他免费官方源未逐家核对的，不写进「已经可对接」清单。

**用户导入的本地文件.** 用户选择本机的 CSV 或 Parquet，并宣告口径。产品不猜测文件是不是总回报。

行情文件至少要有：日期、证券代码、收盘或净值水平、币种，以及一条口径宣告。口径只有两种可选：

- **总回报**：分红或票息已经再投资在这个水平里。
- **价格**：不含分红和票息。

宣告为价格的文件，不能满足任何要求总回报的族。用户改口说「其实是总回报」而不改文件，不算数。

财报文件至少要有：证券代码、科目、数值、报告期结束日、公开时点。公开时点要到日期；能到时点更好。没有公开时点的行不能进入信号。

成分文件至少要有：日期、证券代码、在当日是否在池内。只有一个没有日期的代码清单时，产品把它当成「生成日名单」，结论页必须警示幸存者偏差。

行业文件至少要有：日期、证券代码、分类体系和分类代码。没有日期的，不能打开行业中性。

价差文件可选。有的话至少要有：日期、证券代码、价差（用价格的比例或基点，文件里声明单位）。没有价差文件时，用第 2.2 节已定的成本假设。

文件路径和口径宣告进数据血缘。可实盘交接要能凭冻结下来的输入复现，不能只记一个以后会变的路径。见第 2.8 节。

### 2.6 Yahoo 不再是内置默认源

Yahoo 帮助页说明调整收盘含拆股和现金分红。Yahoo 服务条款禁止未经事先明确许可的自动化采集，也禁止用这些内容做替代数据库。因此：

- 产品不内置 Yahoo 连接器。
- 不把 Yahoo 放进新研究的默认源。
- 不在源失败时回落到 Yahoo。
- 用户持有 Yahoo 书面许可时，许可仍由用户自己负责。产品不为这个许可提供现成连接器。用户可以导入自己有权使用的文件。

### 2.7 配置体验

桌面应用的设置里，数据源和大模型是设置功能的两个分页。研究对话不收集密钥。

数据源页要能做完五件事：

1. **添加账户。** 选择类型：数据商、EDGAR、或本地文件。数据商填写账户别名和密钥。别名是给人看的，例如「我的 Sharadar」。EDGAR 填写联系邮箱。本地文件选择路径并宣告口径。
2. **测试连接。** 按第 1 节。成功时显示这个账户实际覆盖的数据类别，以及行情或财报能追溯到的历史长度。
3. **类别开关。** 用户勾选这个账户要用于哪些类别。测试没有返回的类别不能勾上。
4. **权利确认。** 一句必须勾选的话：「我有权将该数据用于研究。」不勾就不能把这个账户用于新建研究。勾选的时间和别名记入研究，不记密钥。
5. **停用。** 停用只影响以后的新版本。已经开跑的那一版继续用开跑时冻结的源，直到用户确认换源并开新版。

新建研究时，按第 2.3 节检查这一族的「必须」类别。缺任何一类，确认开跑不出现。对话里说明缺的是哪一类，并给出去设置功能里数据源页的入口。用户配好再回来，草稿还在。

确认卡在研究设定摘要旁增加一块**将使用的数据**。每一类一行：类别、源的类型、账户别名、测试时看到的历史长度、口径（总回报或价格；财报则是发布时点的来源）。没有这一块，不能开跑。

### 2.8 与门禁的关系

四关不放松，也不因为「用户自己的数据」而跳过。

- **数据覆盖**按这个源实际取到的历史和字段计算。总回报宣告缺失，覆盖就是不足。全天候仍不能早于 2006-02-03，也不能少一条腿。
- **PIT**仍要求信号只用当时已公开的信息。数据商若只给报告期、不给发布时点，基本面因子不能开跑。
- **待确认**包括换源。换源的确认卡写明从哪个别名换到哪个别名、哪一类数据会变、历史长度变不变。同意后开新版。验证资格按新源重算。
- **验证**不因为换了一家更「好看」的源而沿用旧结论。

研究进行中不得静默切换数据源，也不得在一个源失败时自动改用另一个已配置的源。失败按覆盖门禁处理：容忍度之内的收缩要记录；要跌破就停下来问。停下来时的选择是换源并开新版、缩小范围并开新版、提供本地文件，或停止。没有「先用另一家顶上」的选择。

策略包的数据出处写明：每类数据的源名称、账户别名、拉取时间、口径和覆盖区间。包里写一句：下游若要按同一口径执行或复验，需自备同口径的数据；本包不含密钥，也不附带数据商许可。本地文件若被这次研究使用，可实盘交接的包要带上当时用于复现的冻结输入，不能只留一个日后会改的路径。冻结文件仍不得包含密钥。

## 3. 大模型

大模型只提出假设。收益、持仓、门禁和验证由确定性引擎计算。这是本节判断换模型算哪一层的依据，也是产品设计里「研究方法可以自动推进、经济逻辑必须确认」的落点。

### 3.1 配置什么

设置功能的大模型页可以填写三项：

- **base url**：接入地址。允许填服务商的地址，也允许填本机或自建的地址。
- **api key**：按第 1 节存放。本机模型若不要密钥，此项可以空着，设置页写明「此地址不使用密钥」。
- **模型名**：调用时使用的名字。

第一版以 **OpenAI 兼容接口**为主：用这三项就能发起一次对话请求。本文不记载 Anthropic、Gemini 或其他协议的字段是否相同、路径是否相同。对其他协议的支持列为待定。

### 3.2 测试连接

按第 1 节。成功时白话写明：这个模型名在这个主机上可用。失败时白话写明原因，例如地址没有响应、密钥被拒绝、模型名不存在。不出现完整 api key。

测试只确认「叫得应」。它不代表模型的回答可以当成验证通过。

### 3.3 可复现，以及换模型算哪一层

每一轮研究记录记下当时用的模型：**模型名**，加上 **base url 的主机名和端口**。不记密钥，不记查询参数，不记路径里可能夹带的令牌。没有调用大模型的轮次，写明「本轮未调用大模型」。

一项研究进行中不得静默更换模型。只有用户在设置里主动更换才发生。更换当时就记下来：从哪个模型名和主机名换到哪个，何时换的。这条记录放在该轮的**实现与参数**栏，与研究方法的其他变化放在一起。

**换模型是实现层变更，不开新版，也不走经济逻辑确认。**

现有规则里，必须开新版的是经济逻辑（信号机制、目标市场、验证标准、策略族、主因子）和数据血缘（换数据源、换已定代理）。研究方法、建模方法、参数不开新版。大模型只负责提出假设，不负责把收益算出来，也不负责判定四关。换模型不改变赚谁的钱，不改变验证标准，也不改变进入确定性计算的数据。因此：

- 不因此弹出经济逻辑确认卡。
- 不因此重算或撤销可实盘交接资格。门禁仍只看确定性引擎的结果。
- 换完之后新提出的假设，仍要过原来的四关。模型换了，不能把没过的关变成过。

这和换数据源不同。换数据源改变确定性计算的输入，所以开新版。换模型不改变那些输入。

若用户同一次操作里还改了策略族、验证方法或数据源，那些仍按原规则单独确认。换模型不能代替那些确认。

### 3.4 隐私披露

设置页在保存之前，用白话列出会发往模型端的内容，以及不会发的内容。用户不确认这份说明，不能把该模型用于研究。

**会发往模型端：**

- 研究论点：大致原理和用户原话。
- 为补全策略而整理的文献摘要，不是整篇文献的替代品；摘要本身会发出去。
- 供提出下一步假设用的结果摘要：哪一族、哪一关过或没过、关键参数。不是完整的行情序列。
- 当前这一版的经济逻辑陈述，包括赚谁的钱。

**不会发往模型端：**

- 数据源密钥、大模型 api key、EDGAR 联系邮箱以外的密钥材料。联系邮箱只用于 EDGAR 的 User-Agent，不发给大模型。
- 原始行情全量、财报数值全量、本地数据文件的全文。这些只进确定性引擎。
- 策略包里的冻结数据副本。

**待定，披露页在查清之前写成「是否发送：未定，当前按不发送实现」：**

- 持仓名单和标的池代码。
- 完整的迭代记录，而不是上面的结果摘要。
- 文献原文，而不是摘要。

接入地址的主机在本机时，设置页写明：**使用本地模型，上面会发送的内容不出本机。** 主机不在本机时，写明内容会发到该主机名。主机名用第 3.3 节的记法，不含密钥。

### 3.5 未配置或不可用

新建研究时，大模型未配置，或测试连接不是成功，确认开跑不出现。对话说明缺的是大模型，并给出去设置功能里大模型页的入口。草稿保留。

研究进行中模型不可用：研究进入**已暂停**。这仍是产品设计里的六种状态之一，不新造状态。界面如实说明原因，例如地址没有响应或密钥被拒绝。不静默改用另一个模型，也不假装研究还在跑。暂停期间不计入有效研究时间。用户修好原来的模型，或主动换成另一个并按第 3.3 节留下记录之后，按当前版本继续。换模型本身不开新版。

### 3.6 不同角色是否分开配置

第一版**不**为「提出假设」和「审阅」各配一个模型。设置里只有一套 base url、api key 和模型名。

分开配置列为待定。建议是：以后若要分开，仍然算实现层。每一轮记下该轮每个角色实际用的模型名和主机名，仍然不开新版，仍然不改门禁。审阅模型的输出不能代替确定性引擎的通过或失败。第一版不分开，是为了隐私披露和记录只有一份，避免用户以为换一个审阅模型就能改门禁。

## 4. 验收标准

**数据源**

- 没有配置「必须」类别时，确认开跑不出现，并指出缺的类别和设置入口。
- 权利确认未勾选时，该账户不能被选进研究。
- 确认卡的「将使用的数据」与实际使用的别名一致。
- 研究运行中把行情源从 A 换成 B，若不经确认，持仓不得改按 B 计算。确认之后才是新版。
- A 源失败时，已配置的 B 源不会被自动拿来补。覆盖不足按原门禁停或收缩，并写明是 A 失败。
- 宣告为价格的本地文件不能让股债或全天候通过总回报口径。
- 财报文件没有公开时点时，基本面因子的 PIT 不通过。
- 全天候用已定的五只代码时，数据若早于 2006-02-03，不得把更早的一段算进覆盖。
- 策略包不含密钥，并写明下游需自备同口径数据。

**大模型**

- 未配置或测试未成功时，确认开跑不出现，并指向大模型页。
- 测试成功时界面写明该模型可用；失败时是白话原因，且没有 api key。
- 研究记录里有模型名和主机名，没有密钥，没有查询参数。
- 研究进行中不出现未经用户操作的模型更换。
- 用户主动更换后，实现栏有前后模型名和主机名。版本号不因此增加。四关的通过条件与更换前相同。
- 模型中途不可用时，状态变为已暂停，有效研究时间停止增加，且没有改用另一个模型的结果。
- 保存前能看到会发送和不会发送的清单。本机地址上写明内容不出本机。

**共用**

- 在日志、策略包、迭代记录和测试失败说明里搜索数据源密钥和大模型 api key，结果为空。

## 5. 已知限制

- 产品不代理购买数据，也不审查用户勾选的「我有权使用」是否在法律上成立。
- 五家数据商的价格和字段会变。第 2.5 节是 2026-10-19 的核对，不是长期价目。
- 许多家没有公开保证时点财报或历史买卖价差。基本面因子不能靠这些不确定项开跑。
- EDGAR 不提供总回报，也解决不了股票池的幸存者偏差。
- 个股 5 bp 仍是产品假设。价差源接上之后可以在结论页对照，但不自动改掉已定的 5 bp，除非用户确认换成本假设并开新版。那是验证标准或成本假设的变更。
- Yahoo 不作为默认源之后，没有一个「零配置就能跑完全天候」的内置行情。第一批验收可以用用户有权使用的冻结文件，文件要宣告总回报。
- 大模型的回答不是验证。换模型不改变门禁，也不保证下一轮假设更好。
- 本文只规定 OpenAI 兼容这一种接口。其他协议未核对。

## 6. 待定

- Sharadar 价格表是否已含调整后收盘，descriptions 是不是 GICS。
- EODHD 是否保留修订前的财报原值，以及个人研究的再分发条款。
- Financial Modeling Prep 三档价格与历史长度的稳定对应，以及是否永久保留修订前的值。
- Tiingo 调整价字段、基本面附加包价格、发布日和时点成分。
- Massive 当前股票分档的官方价格、哪一档含历史报价、基本面是不是时点。
- 除 EDGAR 以外，还有哪些免费官方源可以第一批对接。
- 本地 Parquet 与 CSV 的具体编码和时区写法。产品只要求第 2.4 节的字段和口径宣告，文件方言留待实现时另定，不在本文假装已经统一。
- OpenAI 兼容以外的大模型协议。各家路径、字段和鉴权是否相同，本文不记载。
- 持仓名单、标的池代码、完整迭代记录、文献原文会不会发给模型。未定之前按不发送实现。
- 是否为提出假设和审阅分别配置模型。建议见第 3.6 节：第一版不分开；以后分开仍算实现层。
