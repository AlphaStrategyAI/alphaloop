# alphaloop soak emits the overnight release checklist

**Date:** 2026-08-20
**Status:** Approved for this implementation cycle
**Scope:** A local CLI that prints the first-release soak / five-minute
review checklist. Not CI. Not a 95% calculator. Not inventing `FOUND`.
Not unfreezing `webui/`. Not MCP.

## 1. Why this cycle exists

PRD §3.4 / §12: a release candidate must run a real overnight soak and
a five-minute human review. Remaining-work §8 already names the
checklist (two independent profiles, host awake, record outcome tokens,
`kill -9` resume without duplicate `trial_id`s). Operators still have
to hunt markdown. CI must not pretend to be that soak.

## 2. Best-practice basis

1. **Release process ≠ pytest.** The command prints how to run the
   soak. It does not start overnight workers. GitHub Actions must not
   invoke it.
2. **Locked host constraint.** The plan includes `HOST_CONSTRAINT`
   verbatim.
3. **Do not claim alpha.** The plan records `FOUND` / `NO_EVIDENCE` /
   `INCONCLUSIVE` as research conclusions, not profitability.
4. **Independent profiles.** `us-equity-daily` and `crypto-daily` are
   two jobs, never one mixed ranking.

## 3. In-scope requirements

### R1. CLI

`alphaloop soak` prints the plan to stdout and exits 0. It MUST NOT
POST `/v1/jobs`, MUST NOT spawn a worker, MUST NOT write `gates.json`.
Optional `--emit-plan` is the same action.

The printed plan MUST include, verbatim or as locked phrases:

- `HOST_CONSTRAINT`
- `This checklist is not CI.`
- `This soak does not claim alpha or future profitability.`
- `us-equity-daily` and `crypto-daily` as separate jobs
- `FOUND`, `NO_EVIDENCE`, `INCONCLUSIVE`
- `primary evidence` and `stop reason`
- `kill -9` and `trial_id`

It MUST NOT contain `target found`.

### R2. CI lock

`.github/workflows/pytest.yml` MUST NOT mention `soak`.

### R3. Docs

`docs/cli.md` documents `alphaloop soak`. `ROADMAP.md` remaining item
1 points at that command. Remaining-work §8 names `alphaloop soak`.

## 4. Out of scope

- Executing the overnight suite from this command.
- Computing a 95% pass rate.
- \(N_{\mathrm{eff}}\). MCP / cloud workers. Unfreezing `webui/`.

## 5. Acceptance

- Unit: `main(["soak"])` exit 0, plan contents as R1, CI file lock.
- Full unit + e2e pytest as usual (e2e does not run soak overnight).

## 6. Loop exit

Executing the soak on a human's awake host remains a release gate.
\(N_{\mathrm{eff}}\) must not shrink DSR `N`. Later: MCP / cloud
workers.
