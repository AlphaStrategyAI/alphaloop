# 术语中英对照表 v1

**状态：产品定稿中，W1 锁定。**

这是初稿，不是 W1 的定稿。英文栏写「待定」的，W1 之前不得当成已经锁定的界面词。已定词沿用 [设置功能](./settings-config-v1.md) 第 4.4 节。量化术语的英文用业内通用说法。产品专有、而业内没有对应短词的，标「待定」，不在这张表里硬定。

查询和摘录日是 2026-10-19。中文含义以策略族规格、设置功能和 `docs/GLOSSARY.md` 为准。

| 中文 | English | 说明 |
| --- | --- | --- |
| 策略族 | Strategy family | 一套写明经济逻辑、数据和组合规则的策略身份。标识如 `low_volatility` 不随界面语言改变。 |
| 低波 | Low volatility | 持有价格波动更低的股票。标识 `low_volatility`。 |
| 股债再平衡 | Stock-bond rebalance | 在股票与债券之间保持目标比例并再平衡。标识 `stock_bond_rebalance`。 |
| 均值回归 | Mean reversion | 超配近期跌得多、预期向近期锚点回归的股票。标识 `mean_reversion`。 |
| 基本面因子 | Fundamental factor | 按已经发布的财报做横截面排序。标识 `fundamental_factor`。 |
| 全天候 | All weather | 用多类资产覆盖不同的增长和通胀环境，按风险分配，本版不加杠杆。标识 `all_weather`。 |
| 四道门禁 | 待定 | 四关一起决定能否交接。短的英文总称尚未锁定。下面四行是各关本身。 |
| 数据覆盖 | Data coverage | 数据是否达到用户认下的最低覆盖。不够就停，不用另一族的数据把研究做完。 |
| 验证 | Verification | 当前选定的验证方法全部通过，包含重验仍成立。 |
| 待确认清空 | 待定 | 没有悬而未决的确认，包括换族、换主因子、覆盖跌破底线和验证标准变更。英文短词未锁定。 |
| 时点一致性 | Point-in-time consistency | 证据、信号和回测窗口只用当时已公开的信息。方法展示名见术语表。 |
| 未经许可 | Unlicensed | 已定。数据来自对公开网页的自动采集，未获数据方许可，仅供个人研究。 |
| 待选择 | Not selected | 已定。这一市场的来源还没由用户点选。未选不能开跑。 |
| 尚未对接 | Not yet supported | 已定。M2 里五家商业数据商的连接器都显示这个状态，不能填密钥，也不能测试连接。 |
| 幸存者偏差 | Survivorship bias | 已定。用生成日的成分回看历史时，结论页必须警示的那种偏差。 |
| 时点数据 | Point-in-time (PIT) | 已定。按信息当时是否已经公开来使用，而不是按后来修订过的值。 |
| 数据血缘 | Data lineage | 这一版实际用了哪个源、哪只代理、什么口径。换源或换已定代理要开新版。 |
| 数据指纹 | Data fingerprint | 逐列哈希、行数、起止日和口径。默认导出只放指纹，不放数值。 |
| 试验轮数 | 待定 | 已经试过的轮数 N。它要显示，派生草稿还要把它计入累计 M。和「试验次数（X/N）」的短英文尚未分开锁定。 |
| 确认卡 | 待定 | 开跑或等待确认时给人看的那张卡。英文短词未锁定。 |
| 策略包 | Strategy pack | 可交接的策略导出。机器字段和数据指纹不随界面语言改变。 |
| 研究记录 | Research record | 一次研究留下的记录。用户原文和当时的模型文字保持原样。 |
| A 股 | China A-shares | 已定。中国大陆股票市场。与美股分开，不放进同一个新研究的池。 |
| 可开跑 / 开跑就绪 | Ready to run | 已定。确认开跑可以提交时的状态。两个中文写法用同一英文。 |
| 开跑 | Run | 已定。用户确认后让研究开始自主推进的动作。 |
| 知情确认 | Acknowledgment / acknowledge | 已定。名词用 Acknowledgment，动作用 acknowledge。用户按来源确认一次：了解数据未经许可，且仅用于个人研究。 |
| 股票池 | Universe | 已定。一次研究使用的股票集合。新研究的一个池只含一个市场。 |
| 口径 | Data basis | 已定。收益或价格按什么规则计算，例如总回报还是价格指数。 |
| PIT 可能不通过 | May fail the point-in-time check | 已定。时点检查有可能不通过时给用户看的提示，不是已经判定失败。 |
| 技术详情 | Technical details | 错误弹窗里可展开的一层。放引擎原文，不翻译，且不得含密钥。 |
| 分段稳健性检验 | 待定 | 按时间把固定参数的收益分段，比较前缀与下一段是否一致。不是重新估计参数的 walk-forward。英文展示名未锁定。 |
| 集中度 | Concentration | 持仓绝对权重的高分位对夏普的影响。不是市场拥挤度。 |
| 样本外稳定 | Out-of-sample stability | 样本外各段收益方向是否同号。不是分段稳健性检验。 |

待定项在 W1 定稿时改成确定英文，并回写本文件。定稿前界面可以用占位英文，但有占位时 M2 不能出口。
