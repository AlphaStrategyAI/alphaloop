# alphaloop 界面设计 v0.0.1

## 0. 这份文档是什么 / 与产品设计的关系

这是 alphaloop 桌面应用的**界面设计**：壳、token、七屏、状态色、路由、硬约束。实现以 [Figma](https://www.figma.com/design/JXelV0rnUUv5U5w9ur7jtk) 为准，这份是写给工程师的合同。

它的上游是[产品设计 v0.0.1](./product-design-v0_0_1.md)。产品设计回答功能怎么组织、用户怎么用；这份回答屏幕长什么样。凡是两者冲突，以产品设计为准：应当先修订产品设计，再改界面。

它**不是**实现方案。这里不写组件树、不写 CSS、不写路由库。看到「这块代码怎么写」的问题，答案不在这份文档里。

Figma 文件里：`Screens` 是七屏从左到右；`Handoff` 是 token 与约束一览。Token 只用集合 Night / Dark。纸色集合已废弃。

- Figma：https://www.figma.com/design/JXelV0rnUUv5U5w9ur7jtk
- 设计页：`Screens`（0:1）
- Token：集合 `Night` / mode `Dark`（`VariableCollectionId:5:13`）
- 旧集合 `alphaloop / paper (deprecated)` 不要用
- Present：同一文件，可点原型
- 仓库：https://github.com/AlphaStrategyAI/alphaloop
- 画幅：桌面 1440×900

## 这是什么

本机优先的投资策略工坊。一条对话，一次研究。不是行情终端，没有下单入口。

三个块：

1. **研究列表** — 找、进、删。等确认必须一眼看见。
2. **研究对话** — 一条路由上的六个状态。
3. **验证方法库** — 定义验证方法。编辑生成新定义，旧研究不受影响。

## 壳

所有屏共用同一壳。

| 部分 | 规格 |
|---|---|
| 左栏 Rail | 148px 宽，铺满高，`void` 底，右侧 1px `line` |
| Logo | 组件 `Logo / alphaloop`（40:2），**148×148 正方形**，与栏同宽，水平居中 |
| Logo + 导航 | 作为一组，在栏内**纵向居中**，组内间距 4px |
| 导航 | 两项：研究、方法库。17px Noto Serif，左对齐。选中：Medium + `glass` 底 + hairline + 上浮阴影。未选：Regular + `mute`，无底 |
| HostStatus | 绝对定位在栏底（约 y=844, x=20）。文案随屏：等确认 / 本机静 / 运行中 / 已完成 |
| 浏览屏 | 研究列表、草稿、方法库：栏右侧吃掉剩余宽度 |
| 聚焦屏 | 确认开跑、等待确认、运行中、已完成：栏右侧一个居中主列（640–720） |

页面标题不要在内容区再写一遍「研究 / 方法库」，左栏已经是导航。

## Token（Night / Dark）

只实现这一套。

| token | hex | 用途 |
|---|---|---|
| void | `#07090C` | 页面 / 栏底 |
| glass | `#12161C` | 卡片、选中芯片 |
| ink | `#E8EEF5` | 主文字、主图形 |
| mute | `#8B97A8` | 次要文字 |
| line | `#1E2530` | 描边、分割 |
| cyan | `#5EEAD4` | **仅** 等待确认、确认开跑 |
| run | `#60A5FA` | 运行中 |
| ok | `#34D399` | 已完成、通过 |
| stop | `#F87171` | 已结束（未通过） |
| hold | `#FBBF24` | 已暂停 |
| space/8…48 | 8 / 12 / 16 / 24 / 32 / 48 | 间距 |
| radius/10 | 10 | 芯片、小按钮 |
| radius/16 | 16 | 卡片 |

**青色规矩：** `cyan` 和 glow 只给「等待确认」和「确认开跑」。别的屏不要点亮。主按钮在这两处是实心发光。

背景大光斑（Glow* 椭圆）是氛围，不要做成可点控件。

## 列表上的六个状态

确认开跑是独立屏，不出现在列表 pill。列表只有：

| 状态 | 色 | 列表形态 |
|---|---|---|
| 等待确认 | cyan | **主卡片**，置顶，描边发光 |
| 运行中 | run | 普通行 |
| 草稿 | mute | 普通行 |
| 已暂停 | hold | 普通行 |
| 已完成 | ok | 普通行 |
| 已结束（未通过） | stop | 普通行 |

Figma 列表里还留着一条 Filters 图层。**不要做成筛选主路径**，状态以行上 pill 为准。

行操作：进入、删除。等确认行点击 → 等待确认屏。

## 草稿五条设定

右侧始终这五项，未锁定写「未锁定」：

1. 大致原理
2. 资产类别
3. 最长研究时间
4. 第一轮验证方法
5. 最低数据覆盖

谈清这五件才能进确认开跑。

## 路由（原型已接）

SMART_ANIMATE，约 0.32s，EASE_OUT。

```
研究列表  --新建研究-->  草稿
研究列表  --等确认行-->  等待确认
草稿      --(谈清后)-->  确认开跑
确认开跑  --开跑-->      运行中
确认开跑  --返回-->      草稿
等待确认  --同意开新版--> 运行中
等待确认  --不同意继续--> 运行中
等待确认  --暂停-->      研究列表
运行中    --暂停-->      研究列表（状态：已暂停）
```

动效要点：等确认行轻微呼吸（opacity + scale）；主按钮按压缩放。不要把运行日志做成打字机终端。

---

## 硬约束（不要破）

- 桌面应用，不是移动端，不是终端皮肤。
- **没有任何下单、交易、实盘按钮。** 完成态出口是策略包。
- 导出分两种：策略包（实盘交接）/ 研究记录包。完成屏主 CTA 是策略包。
- 方法库编辑 = 新定义。旧研究引用不被改写。
- 暂停、等待确认不耗有效研究额度。
- 青色只属于等待确认和确认开跑。
- 栏宽 148，Logo 必须是 148 正方形，跟栏同宽。

## 建议实现顺序

1. Token + 壳（Rail / Logo / Nav / HostStatus）
2. 研究列表（主卡片 + 行 + 状态 pill）
3. 草稿（对话 + 五条设定）
4. 确认开跑
5. 运行中
6. 等待确认
7. 已完成
8. 方法库
9. 按原型补转场
