# j/k and arrows move between morning jobs without inventing FOUND

**Date:** 2026-08-20
**Status:** Approved for this implementation cycle
**Scope:** Packaged morning job-list keyboard navigation. Not a new
hard gate. Not inventing `FOUND`. Not unfreezing `webui/`. Not soak.
Not \(N_{\mathrm{eff}}\). Not changing Ctrl/Cmd+Enter.

## 1. Why this cycle exists

PRD §4.3: the morning home leads with one conclusion, then evidence.
Ctrl/Cmd+Enter now covers one-minute submit. Five-minute review of
several overnight jobs still requires the mouse. Nielsen heuristic 7:
experts should move between jobs without leaving the keyboard.
GitHub / vim use `j`/`k`; arrows are the discoverable twin.

Arrow keys and letters must not steal caret movement while typing a
hypothesis.

## 2. Best-practice basis

1. **Same selection path as a click.** Navigation MUST call the
   existing `showJob(run_id)` path. `aria-current="true"` stays the
   selected card.
2. **Do not steal typing.** Ignore the chord when `event.target` is
   `INPUT`, `TEXTAREA`, `SELECT`, or `button.load-queued`.
3. **Clamp, do not wrap.** At the first card, Up/`k` stays. At the
   last card, Down/`j` stays. Empty list is a no-op.
4. **Do not invent FOUND.** Navigation cannot override gates.

## 3. In-scope requirements

### R1. Keys

Window `keydown` (same listener family as Ctrl/Cmd+Enter) MUST,
when not typing in a field:

- `ArrowDown` or `j` → select the next `#job-list button` in DOM
  order (newest-first list, so next is older);
- `ArrowUp` or `k` → select the previous button.

`preventDefault` on those keys when they move selection. Unmodified
Enter is unchanged. Ctrl/Cmd+Enter is unchanged.

### R2. `#job-keys-hint`

Inside `#jobs`, after `h2`, a `#job-keys-hint` node MUST contain
this text, verbatim:

`j/k or arrows move between jobs.`

MUST NOT contain `target found`. MUST NOT contain "override".

### R3. Docs

`docs/webui.md` MAY mention job-list `j`/`k` / arrows.
Help / `HOST_CONSTRAINT` / EXAMPLE_SPEC unchanged.

## 4. Out of scope

- Wrapping from last to first. Binding these keys inside the YAML
  textarea. Soak. \(N_{\mathrm{eff}}\). FakeWorker in morning e2e.

## 5. Acceptance

- Static: `#job-keys-hint` locked sentence; script has `ArrowDown`,
  `ArrowUp`, and `showJob(`; ignores INPUT/TEXTAREA/SELECT.
- E2E: two frozen jobs; newest has `aria-current`; ArrowDown moves
  `aria-current` to the second card; detail still a legal outcome.
- Locks: no `target found`; no gate override; no FakeWorker in
  morning e2e.
