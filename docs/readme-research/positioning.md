# 定位结论

日期：2026-10-23。仓库版本：`pyproject.toml` 与桌面包均为 0.2.0，提交以当时的 `main` 为准。证据编号见 [evidence-ledger.md](./evidence-ledger.md)。

## 选定的一种

**主要受众：** 已经自己做日频股票回测的个人研究者。研究市场是美股或 A 股里的一个，不是两个市场混在一次研究里。界面和仓库文档以中文为主，所以优先是读中文、并且愿意自己安装 Python 与桌面依赖的人。

**核心痛点（只保留和当前能力对得上的）：**

1. 自写的向量化回测很容易让信号和成交用到同一根 bar，或在财务数据上用到尚未公告的报告期。证据：E16、E17、E18、E19。本仓库的对应能力只是：成交使用上一根 bar 的信号（E27），以及资料发布日的时点检查（E10）。它不检查标的池时点、复权或财务修订。
2. 试了很多次却只留下最好看的结果，试验次数不进记录。证据：E20 所述的选择偏差文献，以及 E18 里用户自己描述「把样本外调到满意为止」。本仓库对应的是披露本版本轮次和窗口累计 M（E11），不是 Deflated Sharpe，也不是未触碰的留出样本。规格把 Holdout 留在后面（E30）。
3. 研究留在别人的服务器上时，带走的往往是图表而不是冻结的验证定义；免费行情的许可本身也不清楚。证据：E16、E23、E26、E06。本仓库把研究放在本机并导出 zip（E12、E08），同时自己仍通过 yfinance 和 AkShare 取数，而且界面还没有按规格标出「未经许可」（E07）。

**价值主张：** 0.2.0 在你的机器上把一项已经锁定的截面均值回归研究跑完，写下试验次数和五项导出门禁的结果。不下单。不把任意方向自动做成策略。

**首要行动：** 克隆仓库，安装后用命令行确认引擎能启动，再按 README 的侧车步骤打开桌面，新建一项均值回归研究。没有付费入口。没有可下载的安装包。

**关键取舍：** 不用产品定位文档里的「随时丢进一个大致方向、长时间自主研究」做首屏。那个承诺在规格里（E30），引擎只跑旧版逐日 z 分数均值回归（E04）。也不把「加入团队」写成主按钮：没有招聘、没有贡献指南、讨论区关闭（E03）。贡献是次要入口。

## 比较过的另外两种

### 方向 B：自主研究工坊（规格原文）

受众是想丢进模糊方向、走开、回来拿一份验证过的策略的人。吸引力来自 [product-positioning.md](../requirements/product-positioning.md)。0.2.0 兑现不了：对话是五个槽位而不是开放式研究；其余四族不能开跑；设置里的大模型页是「稍后」；默认评审器不调用模型（E04、E07、E34）。写成现有能力就是虚假承诺。保留为文档里的方向，README 明确把它标成比当前版本宽。

### 方向 C：给贡献者的诚实研究引擎

受众是愿意补策略族、数据源或英文文案的工程师。仓库在 2026-10-23 仍有提交，许可证是 MIT（E02）。公开信号不支持把贡献当主行动：0 star、0 fork、无 Release、讨论区关闭、没有开放 Issue、没有 CONTRIBUTING（E03）。主按钮若是「来写代码」，第一次打开的人得不到研究价值。贡献路径写在许可一节，不放在首屏。

## 为什么现在值得试，以及不值得试的人

值得试的条件同时成立：你要的就是日频截面均值回归；你能接受 Yahoo 或 AkShare 的许可状态由你自己判断；你愿意从源码构建桌面，而不是下载安装包；你要的交付物是带门禁的记录，不是下单。

更适合别处的人：要分钟或 tick、要券商、要低波 / 股债 / 基本面 / 全天候、要现成的财务时点数据、要扫大量参数。比较见 [alternatives.md](./alternatives.md)。

## 付费与参与

没有付费方案，所以不写价格，也不暗示「现在买到的是什么」。参与者能投入的是时间：跑一项研究并开 Issue，或按 V1 收口改代码。愿意投入的理由只能是这个问题和这个人有关，不能写成社区已经存在。

## 哪些是已观察到的需求，哪些是假设

已观察到的是公开讨论里反复出现的前视、多重检验和「结果留在平台上」（E16–E19、E23）。这些不是 alphaloop 的用户访谈。没有人在本仓库 Issue 里用自己的话描述这个痛点（E03）。

假设，尚未验证：这类人会愿意为了门禁和试验次数，放弃云平台的数据和模拟交易，并自己完成本机构建。真人验证方案见 [user-validation-plan.md](./user-validation-plan.md)。
