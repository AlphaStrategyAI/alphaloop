# 评审与修改记录

评审者是独立上下文的子代理，模型与写 README 的代理相同（Grok）。这不是真人访谈，不是外部审计，也不能引用成用户反馈。共两轮实质修改。第一轮意见如下；第二轮在修改后重评，结果补在文末。

维度分数是编辑工具。门槛：各维度按百分制 ≥80，且加权总分 ≥90。权重：用户相关性 20、清晰度 15、差异化 15、证据与可信度 20、首次价值体验 15、下一步行动 10、参与路径 5。

## 第一轮（改前草稿）

### A 目标用户（模拟）

理解：本机桌面，只做日频截面均值回归，留下试验次数和记录。不愿克隆：命令行只证明进程在，桌面要 Rust、Node、PyInstaller；默认池是今天的成分回看约十二年；自动迭代只加回看天数。最重要的异议是「这不会因此判时点一致性失败」——首屏用「当时还没有的价格」招人，时点检查却不覆盖成分。要求一次真实导出、成本的算术例子、默认池的覆盖结果。P0 无。P1：价值说大了；快速开始到不了研究；缺填好的五项和两次扣费的数字。分数：相关性 44，清晰度 60，差异化 41，证据 55，首次价值 17，下一步 28，参与 30。

### B 开源产品视角（模拟，不冒充真人）

不愿把下一步交给同事。异议是首屏「再用桌面应用开一项研究」，而第一次能核对的成功是进程 JSON。P0：开跑会拉行情但没有未经许可勾选；「时点通过」会被读成池子干净。P1：没有跑完的桌面研究；EDGAR 身份未验证；版权两个名字；中英手写对齐；对照表把社区经历写成常态；参与是空门。分数：46，63，54，67，18，24，26。

### C 付费决策（模拟）

不批准本月试验。没有可签约主体，付钱的是工程师时间和数据合规。异议是五项导出条件里的「时点一致性已执行且通过」与后文「幸存者偏差不因此失败」可以同时为真，却会被抄进备忘录。P0 同 B 的许可与时点范围。P1：第一次运行不是研究；没有工时；隔天是新窗口；没有人响应。分数：34，48，40，61，16，28，18。

### D 事实核查（模拟，对照了代码）

大部分技术句成立，包括只跑均值回归、五项导出键、两层成本、`shift(1)`、503/300/40/40、版权行、pit 范围、预算 5/5/20。P0：`survivorship_bias_untested` 被写成已经落库的字段，代码里没有这个键。P1：复权被写成「上游若给」，实际个股路径固定复权、基准仍是指数；「未经许可」不在所链的 `docs/GLOSSARY.md`；聚宽 403 被说成收费页，台账里的 403 是社区帖。P2：没有重验记录时该项为真；单名不是截面；回看加 5 与追加预算不是同一个变量；满 20 轮之后每次继续都要再确认。证据分 80。

### E 潜在贡献者（模拟）

不会开 PR。最想改的规格裂缝，正是 README 说不要改的已交付路径。P0（对其角色）：无目标的 PR 邀请、空的 good first issue、参与段指向策略族规格。分数：48，64，70，76，28，40，16。

## 第一轮之后的实质修改

- 删掉「记录里的标记是 `survivorship_bias_untested`」。改写池文件原文、界面「非时点成分」，并写明导出没有该键。
- 时点检查的范围写进导出条件的同一段。明确「通过」不等于池子干净。
- 复权改为代码里的 `auto_adjust=True` 与 `qfq`，基准改为 `^GSPC` 与指数日线。
- 「未经许可」改指 i18n 术语 JSON，不是 `docs/GLOSSARY.md`。
- 聚宽改为会员收费页 URL 的 403（E41），与社区通知（E25）分开。
- 五项对话例句放进桌面步骤。命令行 JSON 标明不是一项研究。
- 成本加了一句标明「不是回测」的算术：年化换手为 1 时，美股门禁再减 0.001。
- 写明回看加 5 与追加预算不是同一个开关；满 20 后每次都要再确认；没有重验记录时该项算通过；单名不是截面。
- 参与段删掉空的 PR 邀请和 good first issue。写明没有可领的开发任务，规格差距不是征稿。
- 版权两个名字不写成同一主体。
- 侧车在装上 `python3.12-venv` 后构建成功，smoke 打印握手成功。图形界面仍未点击。
- 产品定位文档从文档列表的第一项挪到收口之后。

未改、因为产品或访问做不到：图形界面里的完整研究；真实 EDGAR 请求；钉死依赖；把四族做成能跑；把未经许可勾选做进确认流程。这些留在 [missing-materials.md](./missing-materials.md)。
