alphaloop
Static UI mockups · 静态界面稿

An overnight lab, not a console.

Four desktop screens for alphaloop's Web surface, drawn from docs/requirements/product-positioning-requirements.md. The product promise is one minute before bed, a reliable overnight run, and a trustworthy conclusion in five minutes the next morning — so the interface leads with a conclusion and only then shows the evidence behind it. These are static HTML files with a single shared stylesheet. No build step, no backend, no trading.

Screens

01 · MORNING HOME

The five-minute verdict

One conclusion — FOUND, NO_EVIDENCE, or INCONCLUSIVE — set in display type, with primary evidence and stop reason directly beneath it. Then qualifying candidates, the elimination funnel with dominant failure reasons, the methodological revisions the loop made overnight, and the hypotheses queued for human review.

Open the FOUND state → 02 · NEW RESEARCH / PREFLIGHT

Before bed, in one minute

State a hypothesis, choose a market profile, resolve a content-addressed dataset snapshot, tick the predeclared hard gates, read the seven preflight checks and the compute, time and disk budgets, then freeze the protocol. Freeze returns a run_id immediately — and discloses that the host must stay awake.

Open the preflight state → 03 · RUN PROGRESS

Alive without the browser

Supervisor pid, heartbeat age, and the latest complete checkpoint prove the job outlives this tab. Search progress runs one tick per planned trial; budgets burn down; the funnel and trial ledger update on a two-second poll. The outcome stays NONE, and the console cannot override a gate.

Open the running state → 04 · RESULT DETAIL

Evidence, ledger, handoff

One expanded gate with its fold Sharpes, CPCV paths, PBO and nested holdout; five collapsed gates with their raw detail lines; the append-only trial ledger; the run artifact tree. Then the immutable .asb bundle — manual export, YAML only, no executable files — and the queued hypotheses that are never auto-executed.

Verdict palette

FOUND #4ADE9B · emerald Every predeclared gate passed. Never a promise of alpha.
INCONCLUSIVE #F5B544 · amber Evidence set incomplete: data, budget, or technical failure.
NO_EVIDENCE #E0798F · muted rose A required gate failed. Not proof that alpha is absent.
RUNNING · NONE #7EB8FF · blue In flight. Job status is never a research conclusion.

Scope of these mockups

✓ Static HTML + one stylesheet openable from disk, no build, no network
✓ Single local user no team, auth, or approval UI
⊘ No backend or React app nothing here is wired to the Job API
⊘ No trading surface export is the boundary; AlphaStrategy owns execution
⊘ No requirements changed this folder is additive documentation
! Sample data is fabricated plausible quant research values, not real results

alphaloop does not promise alpha or future profitability. The percentage of runs that find alpha is explicitly not a product success metric.
